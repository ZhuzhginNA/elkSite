# ELK Site

Стартовый проект корпоративного сайта на `React + Vite + TypeScript` без собственного backend и без отдельной БД на старте.

Пакетный менеджер проекта: `yarn`.

## Что внутри

- `React SPA` на `Vite`
- `TypeScript`
- `React Router` для табовой навигации
- `TanStack Query` для загрузки и кэширования данных
- раздельные клиенты для внешнего API каталога и headless CMS
- стартовые маршруты:
  - `/`
  - `/catalog`
  - `/gallery`
  - `/documents`
  - `/blog`
  - `/contacts`

## Как в проекте хранится контент

В этом проекте контент делится на 2 источника:

- каталог приходит из внешней системы по API
- остальной сайт хранится в CMS

Под CMS здесь понимается `Content Management System`, то есть админка, в которой менеджер или контент-редактор может менять тексты, загружать изображения, добавлять новости, документы и контакты без участия разработчика.

В типовом варианте в CMS будут жить:

- страницы и SEO-поля
- галерея
- документы и ссылки на файлы
- блог
- контакты

Фронтенд получает эти данные через HTTP API и отображает их. Источником правды для контента становится CMS, а не код в репозитории.

## Архитектурное решение

На старте проект не поднимает собственный backend. Фронтенд работает с двумя внешними источниками:

- API внешней системы каталога
- API headless CMS для текстов, SEO, галереи, документов, блога и контактов

Если позже появятся ограничения по `CORS`, приватные токены, формы, авторизация или серверная агрегация данных, в проект можно добавить тонкий `Node.js BFF` со следующими минимальными контрактами:

- `GET /catalog/...`
- `POST /forms/...`

## Запуск

```bash
yarn install
yarn dev
```

## Переменные окружения

- `VITE_CATALOG_API_BASE` - базовый URL внешнего API каталога
- `VITE_CMS_API_BASE` - базовый URL headless CMS
