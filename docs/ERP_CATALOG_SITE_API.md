# ERP catalog site API

Актуальная версия описания и готовых методов теперь лежит в `docs/ERP_CATALOG_SITE_API_V2.md`.

Используй именно `v2`, потому что там:

- раздельная загрузка `L1` и `L2` категорий;
- облегченные DTO для карточек;
- отдельный метод для изображений;
- документы и изображения больше не смешиваются;
- контракт соответствует текущему `NestJS` backend проекта.
